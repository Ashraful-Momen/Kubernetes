# 🧭 Kubernetes Namespace Command Cheatsheet

## 📌 Basic Namespace Commands

### **List all namespaces**

```sh
kubectl get namespaces
# OR
kubectl get ns
```

### **Create a namespace**

```sh
kubectl create namespace <name>
```

### **Delete a namespace**

```sh
kubectl delete namespace <name>
```

### **Describe a namespace**

```sh
kubectl describe namespace <name>
```

---

## 🚀 Using a Namespace

### **Use namespace for a single command**

```sh
kubectl get pods -n <namespace>
kubectl get svc -n <namespace> <----- here svc means : service . 
kubectl get deploy -n <namespace>
```

### **Set default namespace for your kubectl context**

```sh
kubectl config set-context --current --namespace=<namespace>
```

### **View current namespace**

```sh
kubectl config view --minify | grep namespace:
```

---

## 🏗 Apply or Create Resources in a Namespace

### **Apply YAML to a specific namespace**

```sh
kubectl apply -f <file.yaml> -n <namespace>
```

### **Create a resource with namespace in one command**

```sh
kubectl create deployment myapp --image=nginx -n <namespace>
```

### **Add namespace inside YAML**

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: mypod
  namespace: dev
```

---

## 🔍 View Resources Across Namespaces

### **Get pods in ALL namespaces**

```sh
kubectl get pods --all-namespaces
# OR
kubectl get pods -A
```

### **Get services in all namespaces**

```sh
kubectl get svc -A
```

### **Get deployments in all namespaces**

```sh
kubectl get deploy -A
```

### **Get events in all namespaces**

```sh
kubectl get events -A
```

---

## 🧹 Resource Filtering by Namespace

### **Find resource in specific namespace**

```sh
kubectl get all -n <namespace>
```

### **Delete all resources in a namespace**

```sh
kubectl delete all --all -n <namespace>
```

---

## ⚙️ Switching Namespaces Quickly

### **Using kubens (optional tool)**

Install:

```sh
sudo snap install kubectx --classic
```

Switch namespace:

```sh
kubens <namespace>
```

List namespaces:

```sh
kubens
```

---

## 🧠 Useful Tips

### **Check which namespace a pod is in**

```sh
kubectl get pod <pod-name> -A
```

### **View namespace resource quota**

```sh
kubectl get resourcequota -n <namespace>
```

### **View limit range**

```sh
kubectl get limitrange -n <namespace>
```
