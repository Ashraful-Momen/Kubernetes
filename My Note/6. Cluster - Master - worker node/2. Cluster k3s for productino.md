* **1 VPS as control-plane (master)**

* **NGINX as the Load Balancer** for your web traffic to the workers

* You will deploy using **Kubernetes manifests** (Deployments, Services, Ingress).
* MetalLB will provide LoadBalancer IPs on bare-metal/VPS.

# 2️⃣ Node Preparation (all VPS)

Run on **Ctrl-1 + Worker-1 + Worker-2**:

```bash
# 1. Disable swap
sudo swapoff -a
sudo sed -i '/ swap / s/^/#/' /etc/fstab

# 2. Update system & install required tools
sudo apt update && sudo apt install -y curl apt-transport-https ca-certificates chrony

# 3. Enable time sync
sudo systemctl enable --now chronyd || sudo systemctl enable --now chrony

# 4. Kernel networking settings
cat <<EOF | sudo tee /etc/sysctl.d/99-k3s.conf
net.bridge.bridge-nf-call-iptables = 1
net.ipv4.ip_forward = 1
net.bridge.bridge-nf-call-ip6tables = 1
EOF
sudo sysctl --system
```

Optional: set hostnames

```bash
sudo hostnamectl set-hostname ctrl-1   # on master
sudo hostnamectl set-hostname worker-1 # on worker1
sudo hostnamectl set-hostname worker-2 # on worker2
```

# 3️⃣ NGINX Load Balancer Setup

**On a separate VPS (or master if small cluster)**:

```bash
sudo apt install -y nginx
```

Edit `/etc/nginx/conf.d/k8s_lb.conf`:

```nginx
stream {
    upstream k8s_api {
        server <CTRL-1_PRIVATE_IP>:6443;
    }

    server {
        listen 6443;
        proxy_pass k8s_api;
        proxy_timeout 1m;
        proxy_connect_timeout 10s;
    }
}
```

Enable and restart:

```bash
sudo systemctl enable --now nginx
```

* Your cluster API endpoint will now be the LB VPS IP: `https://<LB_IP>:6443`

# 4️⃣ Install K3s Master (Ctrl-1)

```bash
# On master node
curl -sfL https://get.k3s.io | sh -s - server --disable servicelb
```

> **Notes**:
>
> * `--disable servicelb` because we will use MetalLB for LoadBalancer type services.

Check status:

```bash
sudo k3s kubectl get nodes
sudo k3s kubectl get pods -n kube-system
```

Copy **node token**:

```bash
sudo cat /var/lib/rancher/k3s/server/node-token
```

Copy kubeconfig to your workstation:

```bash
sudo cat /etc/rancher/k3s/k3s.yaml > ~/.kube/config
sudo chown $(id -u):$(id -g) ~/.kube/config
# optionally replace server endpoint with LB IP
```

# 5️⃣ Install K3s Workers (Worker-1, Worker-2)

```bash
export K3S_URL="https://<LB_IP>:6443"
export K3S_TOKEN="<TOKEN_FROM_MASTER>"

curl -sfL https://get.k3s.io | K3S_URL=${K3S_URL} K3S_TOKEN=${K3S_TOKEN} sh -
```

Verify nodes:

```bash
kubectl get nodes
```

You should see:

```
ctrl-1    Ready    master
worker-1  Ready
worker-2  Ready
```

# 6️⃣ Install MetalLB (for LoadBalancer service)

```bash
kubectl apply -f https://raw.githubusercontent.com/metallb/metallb/v0.13.10/manifests/namespace.yaml
kubectl apply -f https://raw.githubusercontent.com/metallb/metallb/v0.13.10/manifests/metallb.yaml
```

Create IP pool for services:

```yaml
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: ConfigMap
metadata:
  namespace: metallb-system
  name: config
data:
  config: |
    address-pools:
    - name: default
      protocol: layer2
      addresses:
      - 10.0.0.240-10.0.0.250
EOF
```

# 8️⃣ Deploy Laravel App & Laravel Horizon

### Example deployment YAML:

```yaml
# laravel-deploy.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: laravel-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: laravel
  template:
    metadata:
      labels:
        app: laravel
    spec:
      containers:
      - name: laravel
        image: your_dockerhub/laravel_app:latest
        ports:
        - containerPort: 8000
---
apiVersion: v1
kind: Service
metadata:
  name: laravel-svc
spec:
  selector:
    app: laravel
  ports:
    - protocol: TCP
      port: 80
      targetPort: 8000
  type: ClusterIP
---
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: laravel-ingress
  annotations:
    kubernetes.io/ingress.class: "nginx"
spec:
  rules:
    - host: laravel.example.com
      http:
        paths:
        - path: /
          pathType: Prefix
          backend:
            service:
              name: laravel-svc
              port:
                number: 80
```

Deploy:

```bash
kubectl apply -f laravel-deploy.yaml
```

Make DNS `laravel.example.com` → Ingress External IP.
