**Flow:**

1. User → NGINX LB → NodePort (Ingress Controller) → Laravel pods
2. HPA scales pods based on CPU/memory/requests

# 2️⃣ Step-by-Step Production Notes

---

## 2.1 Prepare All VPS Nodes

Run on **Ctrl-1 + Worker-1 + Worker-2**:

```bash
# Disable swap
sudo swapoff -a
sudo sed -i '/ swap / s/^/#/' /etc/fstab

# Update and install dependencies
sudo apt update && sudo apt install -y curl apt-transport-https ca-certificates chrony

# Enable NTP
sudo systemctl enable --now chronyd || sudo systemctl enable --now chrony

# Kernel network settings
cat <<EOF | sudo tee /etc/sysctl.d/99-k3s.conf
net.bridge.bridge-nf-call-iptables = 1
net.ipv4.ip_forward = 1
net.bridge.bridge-nf-call-ip6tables = 1
EOF
sudo sysctl --system

# Set hostname (example)
sudo hostnamectl set-hostname ctrl-1   # master
sudo hostnamectl set-hostname worker-1 # worker
sudo hostnamectl set-hostname worker-2 # worker
```

---

## 2.2 Set up External NGINX Load Balancer

**On a separate VPS or master VPS**:

```bash
sudo apt install -y nginx
```

**/etc/nginx/conf.d/k3s_lb.conf**:

```nginx
stream {
    upstream k3s_nodes {
        server <WORKER-1_IP>:30080;
        server <WORKER-2_IP>:30080;
    }

    server {
        listen 80;
        proxy_pass k3s_nodes;
    }

    server {
        listen 443;
        proxy_pass k3s_nodes;
    }
}
```

```bash
sudo systemctl enable --now nginx
```

* LB IP = `my_website.com` DNS

> Note: NodePort 30080 → Ingress Controller HTTP; 30443 → HTTPS

---

## 2.3 Install K3s Master (Ctrl-1)

```bash
curl -sfL https://get.k3s.io | sh -s - server --disable servicelb
```

* Disable built-in ServiceLB (we use external NGINX LB)
* Get token:

```bash
sudo cat /var/lib/rancher/k3s/server/node-token
```

* Copy kubeconfig to workstation:

```bash
sudo cat /etc/rancher/k3s/k3s.yaml > ~/.kube/config
sudo chown $(id -u):$(id -g) ~/.kube/config
# optionally replace server IP with LB IP
```

Check cluster:

```bash
sudo k3s kubectl get nodes
sudo k3s kubectl get pods -n kube-system
```

## 2.4 Install Worker Nodes

On **Worker-1 and Worker-2**:

```bash
export K3S_URL="https://<CTRL-1_IP>:6443"
export K3S_TOKEN="<MASTER_NODE_TOKEN>"

curl -sfL https://get.k3s.io | K3S_URL=${K3S_URL} K3S_TOKEN=${K3S_TOKEN} sh -
```

Check:

```bash
kubectl get nodes
```

You should see: `ctrl-1`, `worker-1`, `worker-2` Ready.

## 2.6 Deploy Laravel App with HPA

**laravel-deploy.yaml**

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: laravel-app
spec:
  replicas: 2
  selector:
    matchLabels:
      app: laravel
  template:
    metadata:
      labels:
        app: laravel
    spec:
      containers:
      - name: laravel
        image: your_dockerhub/laravel_app:latest
        ports:
        - containerPort: 8000
        resources:
          requests:
            cpu: "100m"
            memory: "200Mi"
          limits:
            cpu: "500m"
            memory: "500Mi"
---
apiVersion: v1
kind: Service
metadata:
  name: laravel-svc
spec:
  selector:
    app: laravel
  ports:
  - protocol: TCP
    port: 80
    targetPort: 8000
  type: ClusterIP
---
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: laravel-ingress
  annotations:
    kubernetes.io/ingress.class: "nginx"
spec:
  rules:
  - host: my_website.com
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: laravel-svc
            port:
              number: 80
---
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
metadata:
  name: laravel-hpa
spec:
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: laravel-app
  minReplicas: 2
  maxReplicas: 5
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 50
```

Apply:

```bash
kubectl apply -f laravel-deploy.yaml
```

* DNS: `my_website.com` → NGINX LB IP

* HPA will scale pods automatically based on CPU usage.
