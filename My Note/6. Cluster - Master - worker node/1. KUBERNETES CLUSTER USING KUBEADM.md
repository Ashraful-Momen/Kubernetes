# 🚀 PRODUCTION-READY KUBERNETES CLUSTER USING KUBEADM

**Goal:** Build a professional cluster with 1 or more masters + workers.

---

# 🧠 REQUIREMENTS (PRODUCTION LEVEL)

## Hardware recommended:

* Master nodes: **3 control-plane nodes** (for HA)
* Worker nodes: 2+
* CPU: ≥ 2 core / node
* RAM: ≥ 4GB master, 2GB worker
* Storage: SSD recommended

---

# ⚠️ Disable swap (required)

```bash
sudo swapoff -a
sudo sed -i '/ swap / s/^/#/' /etc/fstab
```

---

# 🌐 Networking prerequisites

```bash
sudo modprobe br_netfilter
echo '1' | sudo tee /proc/sys/net/bridge/bridge-nf-call-iptables
```

---

# 🧊 Install container runtime: containerd

```bash
sudo apt install -y containerd
sudo mkdir -p /etc/containerd
containerd config default | sudo tee /etc/containerd/config.toml
sudo systemctl restart containerd
sudo systemctl enable containerd
```

# 🗝️ VERY IMPORTANT — SAVE JOIN TOKEN OUTPUT

You will see something like:

```bash

    --discovery-token-ca-cert-hash sha256:zzzzzzzzzz
```

# ❗ If join token LOST or expired

## Create new join token manually:

```bash
kubeadm token create
```

Example output:

```

```

# 🛗 PROMOTE WORKER TO MASTER (Control Plane)

> Convert worker to secondary master

On existing master:

```bash
kubectl get nodes -o wide
```

Choose node: “worker-01”

---

## On worker node:

```bash
sudo kubeadm join <MASTER-IP>:6443 --token <TOKEN> \
 --discovery-token-ca-cert-hash sha256:<HASH> \
 --control-plane
```

Afterwards:

```bash
kubectl get nodes
```

You will see:

```
worker-01   Ready    control-plane
```

✔ Now it’s a master

---

# 🏛️ PRODUCTION HA MULTI-MASTER SETUP

You need:

* 3 masters
* External load balancer OR keepalived VIP
* Shared API endpoint

Example:

```
kubeadm init --control-plane-endpoint "k8s-lb:6443" \
  --upload-certs \
  --pod-network-cidr=192.168.0.0/16
```

Then to join 2nd & 3rd master:

```bash
kubeadm join k8s-lb:6443 --token <TOKEN> \
 --discovery-token-ca-cert-hash sha256:<HASH> \
 --control-plane \
 --certificate-key <KEY>
```

# 🔥 FIREWALL RULES (PRODUCTION)

On master allow:

```
6443       — Kubernetes API
2379–2380  — etcd
10250      — kubelet
10251      — kube-scheduler
10252      — kube-controller-manager
10257      — kube-controller-manager (new)
10259      — kube-scheduler (new)
```

On workers:

```
10250  — kubelet
30000–32767  — NodePort Services
```

If using UFW:

```bash
sudo ufw allow 6443/tcp
sudo ufw allow 2379:2380/tcp
sudo ufw allow 10250/tcp
sudo ufw allow 10251/tcp

sudo ufw allow 10257/tcp
sudo ufw allow 10259/tcp
```
