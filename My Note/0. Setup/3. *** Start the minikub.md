Ah! That error means **kubectl is trying to contact a Kubernetes API server, but none is running** on your local machine (`localhost:8080`). This is normal if **Minikube is not started yet**.

Here’s how to fix it:

---

### 1️⃣ Start Minikube

```bash
minikube start
```

* This will start a single-node cluster locally (master + worker in one VM/container).
* If you want a specific driver (like Docker), you can run:

```bash
minikube start --driver=docker
```

---

### 2️⃣ Check kubectl context

```bash
kubectl config current-context
```

* Should show `minikube`. If not, switch to it:

```bash
kubectl config use-context minikube
```

---

### 3️⃣ Verify nodes

```bash
kubectl get nodes
```

* Now you should see something like:

```
NAME       STATUS   ROLES    AGE   VERSION
minikube   Ready    master   5m    v1.xx.x
```

---

### 4️⃣ Optional: Check cluster info

```bash
kubectl cluster-info
```

* Confirms API server is running.

---

💡 **Tip:**

* Every time you restart your PC, you may need to run `minikube start` again.
* If Minikube fails, check Docker is running (`docker ps`).
