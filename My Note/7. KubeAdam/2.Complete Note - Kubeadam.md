## Kubeadam: K8s Cluster Setup on EC2  
*Lightweight Kubernetes cluster deployment using kubeadm on AWS infrastructure*

```
    ┌─────────────────────────────────────────┐
    │              AWS EC2 Instances          │
    ├─────────────────────────────────────────┤

    │  │ t2.medium  │────│ t2.micro   │      │

    │  └────────────┘    └────────────┘      │
    │                     ┌────────────┐      │
    │                     │ Worker Node│      │

            │                    │
    [Control Plane]       [Worker Nodes]
    Ports: 6443, 2379    Ports: 10250, 30000-32767
```

# goto the aws console and create a ec2 instance with ubuntu : 1 master node, 2 worker node

**EC2 Specifications:**
- Master: t2.medium (2 vCPU, 4GB RAM), 20GB disk
- Workers: t2.micro (1 vCPU, 1GB RAM), 20GB disk
- Ubuntu 22.04 LTS
- Enable auto-assign public IP
- Use existing key pair or create new SSH key

# EC2 : allow port : 
----------------------
**Security Group Rules (for all nodes):**
```yaml
Inbound:
  - SSH: 22 (0.0.0.0/0)
  - Kubernetes API: 6443 (Node CIDR)
  - Kubelet API: 10250 (Node CIDR)
  - etcd: 2379-2380 (Master only, Node CIDR)
  - NodePort: 30000-32767 (0.0.0.0/0)
  - ICMP: All (Node CIDR) - for troubleshooting
  
Outbound: All traffic
```

# Now Login every ec2 :

**Step 0: Initial Setup (All Nodes)**
```bash
# SSH into each node
ssh -i your-key.pem ubuntu@<EC2_PUBLIC_IP>

# Set hostnames
sudo hostnamectl set-hostname master-node    # On master
sudo hostnamectl set-hostname worker-node1   # On worker1
sudo hostnamectl set-hostname worker-node2   # On worker2

# Update /etc/hosts on ALL nodes
cat <<EOF | sudo tee -a /etc/hosts
10.0.1.10 master-node
10.0.1.11 worker-node1
10.0.1.12 worker-node2
EOF

# Disable firewall (or configure properly)
sudo ufw disable
```

**Step 1: System Configuration (All Nodes)**
```bash
# Update and install prerequisites
sudo apt update && sudo apt upgrade -y
sudo apt install -y apt-transport-https ca-certificates curl gnupg2 software-properties-common

# Add Docker GPG key and repo
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Add Kubernetes repo
curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.28/deb/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/kubernetes-apt-keyring.gpg
echo "deb [signed-by=/etc/apt/keyrings/kubernetes-apt-keyring.gpg] https://pkgs.k8s.io/core:/stable:/v1.28/deb/ /" | sudo tee /etc/apt/sources.list.d/kubernetes.list

# Install packages
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io kubelet kubeadm kubectl
sudo apt-mark hold kubelet kubeadm kubectl docker-ce docker-ce-cli

# Configure Docker daemon
cat <<EOF | sudo tee /etc/docker/daemon.json
{
  "exec-opts": ["native.cgroupdriver=systemd"],
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "100m"
  },
  "storage-driver": "overlay2"
}
EOF

sudo systemctl daemon-reload
sudo systemctl restart docker
sudo systemctl enable docker containerd kubelet
```

**Step 2: Kernel Modules & Sysctl (All Nodes)**
```bash
# Load kernel modules
sudo modprobe overlay
sudo modprobe br_netfilter

# Make modules persistent
cat <<EOF | sudo tee /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF

# Configure sysctl
cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-iptables  = 1
net.bridge.bridge-nf-call-ip6tables = 1
net.ipv4.ip_forward                 = 1
EOF
sudo sysctl --system

# Disable swap permanently
sudo swapoff -a
sudo sed -i '/ swap / s/^\(.*\)$/#\1/g' /etc/fstab
```

**Step 3: Initialize Master Node (ONLY on Master)**
```bash
# Initialize cluster with pod network CIDR
sudo kubeadm init --pod-network-cidr=10.244.0.0/16 \
  --apiserver-advertise-address=$(hostname -I | awk '{print $1}') \
  --control-plane-endpoint=$(hostname -I | awk '{print $1}')

# Set up kubeconfig
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config

# Save join command for later
kubeadm token create --print-join-command > join-command.sh
chmod +x join-command.sh

# Install Flannel network plugin
kubectl apply -f https://raw.githubusercontent.com/flannel-io/flannel/master/Documentation/kube-flannel.yml

# OR Install Calico
# kubectl apply -f https://docs.projectcalico.org/manifests/calico.yaml

# Check cluster status
kubectl get nodes
kubectl get pods --all-namespaces
```

**Step 4: Join Worker Nodes (ONLY on Workers)**
```bash
# Copy join command from master or run this on each worker:
ssh ubuntu@master-node 'cat join-command.sh' | sudo bash

# Alternative: If you have the join command manually
# sudo kubeadm join <MASTER_IP>:6443 --token <TOKEN> \
#   --discovery-token-ca-cert-hash sha256:<HASH>
```

**Step 6: Optional - Dashboard Setup**
```bash
# Deploy Kubernetes Dashboard
kubectl apply -f https://raw.githubusercontent.com/kubernetes/dashboard/v2.7.0/aio/deploy/recommended.yaml

# Create admin user
cat <<EOF | kubectl apply -f -
apiVersion: v1
kind: ServiceAccount
metadata:
  name: admin-user
  namespace: kubernetes-dashboard
EOF

# Create cluster role binding
cat <<EOF | kubectl apply -f -
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: admin-user
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-admin
subjects:
- kind: ServiceAccount
  name: admin-user
  namespace: kubernetes-dashboard
EOF

# Get token for dashboard login
kubectl -n kubernetes-dashboard create token admin-user

# Access dashboard via proxy
kubectl proxy
# Then visit: http://localhost:8001/api/v1/namespaces/kubernetes-dashboard/services/https:kubernetes-dashboard:/proxy/
```

**Troubleshooting Commands:**

```bash
# Check logs
sudo journalctl -u kubelet -f
sudo journalctl -u docker -f

# Check kubelet status
sudo systemctl status kubelet
sudo systemctl status docker

# Get cluster info
kubectl describe nodes
kubectl get events --sort-by='.metadata.creationTimestamp'
```

**Important Notes:**
1. All nodes must be in same VPC and subnet
2. Ensure clock synchronization: `sudo timedatectl set-ntp true`
3. Master node requires minimum 2GB RAM
4. Worker nodes join via private IP (use VPC endpoint)
5. Consider using EBS volumes for persistent storage
6. For production, set up proper TLS certificates and RBAC
