
How to install helm: 
---------------------
# Install Helm on Parrot OS (Debian-based)

1. Add Helm GPG key:
curl https://baltocdn.com/helm/signing.asc | sudo apt-key add -

2. Add Helm repository:
echo "deb https://baltocdn.com/helm/stable/debian/ all main" | sudo tee /etc/apt/sources.list.d/helm-stable-debian.list

3. Update packages:
sudo apt update

4. Install Helm:
sudo apt install helm -y

5. Verify:
helm version

    chart.yaml: 
    -----------
    apiVersion: v2

    # Helm chart metadata (name, description, ***type: application, version, appVersion, maintainers) define by user in chart.yaml

    name: my-application # Name of the Helm chart
    description: A Helm chart for deploying My Application
    type: application
    version: 1.0.0 # Version of the Helm chart
    appVersion: "1.0.0" # Version of the application being deployed
    maintainers:
    - name: Jane Doe
