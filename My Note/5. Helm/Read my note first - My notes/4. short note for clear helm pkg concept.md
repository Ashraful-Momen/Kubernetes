# 📦 Helm Chart Structure (minimal required)

```
myapp/
  Chart.yaml
  values.yaml
  templates/
      deployment.yaml
      service.yaml
      ingress.yaml
```

---

# Chart.yaml

```yaml
apiVersion: v2
name: myapp
version: 0.1.0
description: Simple web application chart (works for Django / Laravel / Node / React API)
```

✔ Just metadata, nothing complicated.

---

# values.yaml

```yaml
image:
  repository: myapp-image   # your Docker image name
  tag: latest               # image tag
  pullPolicy: IfNotPresent

replicaCount: 1

service:
  type: ClusterIP
  port: 80

ingress:
  enabled: true
  className: nginx
  hosts:
    - host: myapp.local
      path: /
```

✔ These are user-friendly variables that can be changed
✔ Helm injects these values into the YAML templates

---

# templates/deployment.yaml

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ .Release.Name }}
spec:
  replicas: {{ .Values.replicaCount }}
  selector:
    matchLabels:
      app: {{ .Release.Name }}
  template:
    metadata:
      labels:
        app: {{ .Release.Name }}
    spec:
      containers:
        - name: {{ .Release.Name }}
          image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
          imagePullPolicy: {{ .Values.image.pullPolicy }}
          ports:
            - containerPort: 80
```

✔ This is how Helm injects variables from `values.yaml`
✔ Using:

```
{{ .Values... }}
```

---

# templates/service.yaml

```yaml
apiVersion: v1
kind: Service
metadata:
  name: {{ .Release.Name }}
spec:
  type: {{ .Values.service.type }}
  selector:
    app: {{ .Release.Name }}
  ports:
    - port: {{ .Values.service.port }}
      targetPort: 80
```

✔ Exposes your pod internally
✔ Service port maps to container 80

---

# templates/ingress.yaml

```yaml
{{- if .Values.ingress.enabled }}
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: {{ .Release.Name }}-ingress
  annotations:
    kubernetes.io/ingress.class: {{ .Values.ingress.className }}
spec:
  rules:
  {{- range .Values.ingress.hosts }}
    - host: {{ .host }}
      http:
        paths:
          - path: {{ .path }}
            pathType: Prefix
            backend:
              service:
                name: {{ $.Release.Name }}
                port:
                  number: {{ $.Values.service.port }}
  {{- end }}
{{- end }}
```

✔ Notice the Helm template logic:

```
{{- if .Values.ingress.enabled }}
```

Meaning:
If user enables ingress → YAML rendered
If not → YAML ignored

# 🚀 Installing the app (first time)

```
helm install myapp ./myapp
```

---

# 🆙 Updating with new version (EXAMPLE)

```
helm upgrade myapp ./myapp
```

Or upgrade with new values:

```
helm upgrade myapp ./myapp -f values.yaml
```

Or override quickly:

```
helm upgrade myapp ./myapp --set replicaCount=3
```
