# 🧠 What is Helm?

Helm is the **package manager for Kubernetes** — similar to `apt`, `yum`, or `npm`, but for Kubernetes apps.

Helm packages are called **charts**.

---

# 🛠 How to Install Helm (Parrot OS / Debian-based)

```bash
# 1. Add Helm GPG key
curl https://baltocdn.com/helm/signing.asc | sudo apt-key add -

# 2. Add Helm repository
echo "deb https://baltocdn.com/helm/stable/debian/ all main" \
| sudo tee /etc/apt/sources.list.d/helm-stable-debian.list

# 3. Update package index
sudo apt update

# 4. Install Helm
sudo apt install helm -y

# 5. Verify installation
helm version
```

# 🧩 Helm Chart Structure

Helm uses several key components:

```
Chart.yaml       # Chart metadata
values.yaml      # Config values like .env
templates/       # YAML templates (deployment, service etc)
templates/_helpers.tpl  # helper functions
```

---

# ⚙️ Chart.yaml (metadata)

```yaml
apiVersion: v2
name: my-application
description: A Helm chart for deploying My Application
type: application
version: 1.0.0
appVersion: "1.0.0"
maintainers:
  - name: Jane Doe
    email: 6Dm0k@example.com
```

✔ Defines name, version, metadata
✔ NOT related to Kubernetes runtime
✔ Values here accessed using `.Chart.*`

---

# 🗂 templates/ directory

Inside this folder we create Kubernetes manifests:

```
deployment.yaml
service.yaml
configMap.yaml
secret.yaml
ingress.yaml
_helpers.tpl
```

---

# 🧮 _helpers.tpl (VERY IMPORTANT)

```yaml
{{- define "django-app.name" -}}
{{- .Chart.Name -}}
{{- end -}}

{{- define "django-app.fullname" -}}
{{- printf "%s-%s" .Release.Name (include "django-app.name" .) | trunc 63 | trimSuffix "-" -}}
{{- end -}}
```

✔ We define reusable names
✔ Use them anywhere with:

```yaml
{{ include "django-app.name" . }}
```

`.Chart.* → from Chart.yaml`
`.Values.* → from values.yaml`

---

# 🔐 values.yaml (like a .env file)

```yaml
replicaCount: 3

image:
  repository: my-django-app
  tag: "1.0.0"
  pullPolicy: IfNotPresent

resources:
  limits:
    cpu: 500m
    memory: 512Mi
  requests:
    cpu: 250m
    memory: 256Mi

service:
  type: ClusterIP
  port: 80

ingress:
  enabled: true
  host: "myapp.mydomain.com"
```

✔ Used to configure deployments
✔ Override values at install time

---

# 🔄 Value Resolution Flow (easy diagram)

```
values.yaml  (.Values.*)
chart.yaml   (.Chart.*)
_helpers.tpl (include "...")
templates/*.yaml  (Deployment, service etc)
```

✔ Helm merges everything into a **rendering context `.`**

---

# 📦 deployment.yaml

```yaml
replicas: {{ .Values.replicaCount }}
...
containers:
  - image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
```

✔ Getting values from values.yaml
✔ `include` gets values from helper

---

# 🌐 service.yaml

```yaml
name: {{ include "django-app.name" . }}-service
type: {{ .Values.service.type }}
port: {{ .Values.service.port }}
```

---

# 🔑 secret.yaml

```yaml
Django_SECRET_KEY: {{ .Values.secrets.Django_SECRET_KEY | b64enc | quote }}
```

✔ Automatically base64-encodes secret

---

# 🌍 ingress.yaml (with conditional enable)

```yaml
{{- if .Values.ingress.enabled }}
...
{{- end }}
```

✔ If ingress disabled → whole file is ignored.

# 🧪 EXAMPLE – ingress.host logic

```yaml
host: {{- if .Values.ingress.host }}{{ .Values.ingress.host }}{{ else }}"{{ include "django-app.name" . }}.example.com"{{ end }}
```

✔ If host provided → use it
✔ else → default:

# 🚀 Helm Commands (with explanation)

```bash
helm install myapp ./mychart                    # Install chart
helm install myapp ./mychart -f values.yaml     # Install using values file
helm install myapp ./mychart --set replicas=5   # Override value
```

```bash
helm upgrade myapp ./mychart                    # Upgrade chart
helm upgrade myapp ./mychart -f values.yaml     # Upgrade with new values.yaml
helm upgrade myapp ./mychart --set replicas=10  # Live update
```

```bash
helm uninstall myapp                            # Delete deployment
helm list                                       # List installed releases
```

```bash
helm template ./mychart                         # Render manifests locally
helm lint ./mychart                             # Validate chart
```

```bash
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update
helm search repo nginx                          # Search charts
```
