# ✅ **ASCII Explanation: metadata, labels, selector, app**

```
+-----------------------------------------------------+
|                DEPLOYMENT (Red Box)                 |
+-----------------------------------------------------+
| apiVersion: apps/v1                                 |
| kind: Deployment                                    |
|                                                     |
| metadata:                                           |
|   name: nginx-deployment   <-- NAME of this object  |
|   labels:                                           |
|     app: nginx              <-- LABEL attached here |
|                                                     |
| spec:                                               |
|   replicas: 2                                       |
|   selector:                                         |
|     matchLabels:                                    |
|       app: nginx          <-- SELECTOR looks for    |
|                               Pods with label app=nginx
|                                                     |
|   template:                                         |
|     metadata:                                       |
|       labels:                                       |
|         app: nginx       <-- POD gets same LABEL    |
|                                                     |
|     spec:                                           |
|       containers:                                   |
|         - name: nginx                               |
|           image: nginx:latest                       |
|           ports:                                    |
|             - containerPort: 80                     |
+-----------------------------------------------------+



+-----------------------------------------------------+
|                   SERVICE (Green Box)               |
+-----------------------------------------------------+
| apiVersion: v1                                      |
| kind: Service                                       |
|                                                     |
| metadata:                                           |
|   name: nginx-service   <-- NAME of the service     |
|                                                     |
| spec:                                               |
|   selector:                                         |
|     app: nginx        <-- SERVICE must match LABEL  |
|                                                      |
|   ports:                                             |
|     - protocol: TCP                                  |
|       port: 80        <-- service port (external)    |
|       targetPort: 80  <-- pod’s containerPort        |
|                                                      |
|   type: LoadBalancer                                 |
+-----------------------------------------------------+
```

# 🧠 **How They Connect — ASCII Relationship Map**

```
       [ Deployment ]
              |
              | creates Pods with:
              |
         label: app=nginx
              |
              v
       +----------------+
       |   Pod(s)       |
       | label: nginx   |
       +----------------+
              ^
              |
              | Service SELECTS Pods using:
              |
       selector: app=nginx
       [ Service ]
```

✔ Deployment gives **labels** to pods
✔ Service uses **selector** to find those pods

---

# 🎯 **One-Line Memory Notes**

```
metadata = name + labels (identity of the object)
label    = tag attached to objects (key:value)
selector = filter used by Service/Deployment to find matching labels
app      = common key in labels (e.g., app=nginx)
```
